Languages

From the openEHR template or archetype (original language, translations, description details). Outline colour on pills. Click to show or hide a bag.

Families

Fill colour. Click to show/hide a key-prefix family.

Families are dotted key prefixes such as L10n. (OPT multilingual workaround) and a. (UI-hint / automation annotations). Unprefixed keys (comment, design note, ui) stay in their own family. Language bags cannot be added here — they follow the model's supported languages.

Definition tree

Every node stays visible. Pills show annotation values from every enabled language bag; extra pills wrap onto more rows.
